zone drawing

Per-feature: draw the floor areas THIS feature cares about (a queue, a doorway, a private room). No calibration needed -- a zone is a polygon in one camera's own pixel space, checked only against that camera's own detections at run time. For a one-time site setup (needed only if a later feature wants a real floor position), use reference_ui/calibration/calibration_app.py instead.

Click ANY NUMBER of points (>= 3) tracing the zone's edge on THIS camera's own image. The dashed line shows where it will close automatically. Click "close zone" when done to name and save it -- checked only against this camera's own detections, no calibration needed.

zones are per camera -- no calibration needed

Pick a camera tab, click ANY NUMBER of points (3 or more) tracing the real area you want on THAT camera's own image, then "close zone" -- it connects your last point straight back to your first point automatically, you don't click the first point again. A detection counts if its feet land inside the region, checked only against that one camera's own detections. No real-world measurement, no calibration, nothing to get inconsistent across cameras.

saving -- zones save the moment you close one, AND any time you click "save zones now" (same file, just an explicit trigger if you want the confirmation).
