/cameras — the site camera table

The real, server-side table (features/data/cameras.json) — persisted, and survives a restart. Define a camera once, then tick which features watch it; each feature reads its list from here. Quality is a fraction of native resolution and is safe to change: the calibration is rescaled from the actual frame size, so lowering it does not move anyone on the floor. Changing quality re-bootstraps /people (track ids are lost).
